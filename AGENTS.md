# AGENTS.md

## Purpose

`serve-md` is a Go CLI and local server for browsing Markdown through an embedded Vite/React UI.

## Boundaries

- Go CLI/server: `main.go`, `cmd/`, and Go files under `internal/`.
- Frontend source: `internal/web/frontend/` and `internal/web/*.ts`.
- `internal/web/dist/` is generated by `pnpm build:web`; never edit it directly.

## Conventions

- Make minimal, surgical changes.
- Preserve strict TypeScript safety: no `any`, non-null assertions, or type assertions.
- Format Go with `gofmt`; test behavior, not implementation details.

## Iteration

Use `testdata/markdown` and `pnpm dev` while iterating. Verify with `go test ./...`, `pnpm test:web`, `pnpm typecheck`, and `pnpm test:browser` as applicable.
